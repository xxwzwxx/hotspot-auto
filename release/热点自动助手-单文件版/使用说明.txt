热点自动助手 1.0.0 · 使用说明
========================================

这是什么
  校园网自动登录 + 一键开移动热点的小工具。绿色单文件，不需要安装 Python，也不需要管理员权限。

能跑在哪些系统
  · Windows 10 / Windows 11（64 位）
  · Windows 7 / 8 / 8.1 不支持（程序基于 Python 3.13，本身就不支持这些老系统）
  · 不需要 .NET、不需要额外运行库，系统自带的组件就够

第一次使用（三步）
  1. 把整个文件夹（单文件版就是一个 exe）拷到电脑上任意位置，双击「热点自动助手.exe」。
  2. 打开「配置」页，填 Portal 地址（默认 http://10.10.10.10）、API 端口（默认 801）、
     登录账号、登录密码，点右上角「保存配置」。
  3. 回「概览」页，点「一键登录并开热点」。

  · 没填账号时点按钮会弹提示，并自动跳到配置页。
  · 配置和日志都写在 exe 同一个目录里：campus-config.json / settings.json /
    campus.log / hotspot.log。换电脑时把 exe 拷过去，重填一次账号即可。

两个版本的区别（功能完全一样，任选一个）
  · 单文件版（热点自动助手.exe）：只有 1 个文件，最方便。每次启动会先把内容解到系统临时目录，
    个别杀毒软件比较敏感，首次启动会慢 1~2 秒。
  · 文件夹版：exe + _internal 文件夹，_internal 必须和 exe 放在一起，不能单独拷走 exe。
    启动更快、不容易被拦截。

首次运行时 Windows 可能拦一下
  程序没有购买代码签名，Windows 10/11 的 SmartScreen 会提示「Windows 已保护你的电脑」。
  点「更多信息」→「仍要运行」即可。如果被 360 / 腾讯管家 拦截，请选择「允许程序运行」。

日常使用
  · 点窗口右上角的 × = 收进托盘（右下角）；双击托盘图标回到窗口，右键托盘可以快速执行或退出。
  · 「设置」里勾上「开机时自动启动」+「启动后自动登录并开热点」，开机就会自己在托盘里连好网，
    连好后弹一条通知，不用点任何按钮。
  · 勾上「断网后自动重连校园网」：探到外网不通、且校园网 Portal 可达时，会自动重新登录。
  · 同一台电脑只能开一份，第二次双击会把已经打开的窗口叫到前面。

卸载
  退出程序 → 在「设置」里取消勾选「开机时自动启动」→ 删除整个文件夹。
  程序不往系统目录写文件，注册表里只动 HKCU 的启动项。

遇到问题时
  · 登录提示失败但网页能打开：校园网的在线列表接口不稳定，程序会用「能不能上网」兜底判断，
    详情看「日志」页。
  · 热点开不起来：Windows 设置 → 网络和 Internet → 移动热点，先确认这块网卡支持热点。
  · 想看程序到底做了什么：打开「日志」页，或者看 exe 旁边的 campus.log / hotspot.log。
